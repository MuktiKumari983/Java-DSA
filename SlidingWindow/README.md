# Sliding Window

The Sliding Window technique is used to solve problems involving contiguous subarrays or substrings efficiently.

---


---

##  Types

### 1. Fixed Size Sliding Window
- Window size remains constant.
- Used for maximum/minimum sum or average.

Example:
- Maximum Average Subarray I

---

### 2. Variable Size Sliding Window
- Window size changes based on a condition.
- Used for longest/shortest substring or subarray.

Example:
- Longest Substring Without Repeating Characters

---

## ⏱ Complexity

- Time: O(n)
- Space: O(1) / O(k)
